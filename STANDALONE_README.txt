QUICK START
-----------
1. Double-click RM-Insta-Depo.exe to launch
2. The overlay will appear in the top-left corner
3. Press F8 to show/hide the overlay
4. Use the hotkeys to automate your tasks!


HOTKEYS
-------
F1  - Depo (Main function)
F2  - Loot Output
F3  - Loot Input
F4  - Recipe Search (opens search dialog)
F5  - Select Resolution (choose your screen resolution)
F6  - Toggle Auto Click (ON/OFF)
F8  - Show/Hide GUI


FIRST TIME SETUP
----------------
1. Launch the application
2. Press F5 to open the Resolution Selector
3. Choose your screen resolution:
   - 3840 x 2160 (4K UHD)
   - 2560 x 1440 (QHD)
   - 1920 x 1080 (Full HD)
4. Click Apply
5. You're ready to use the app!

HOW TO USE
----------
Recipe Search:
  1. Press F4 to open Recipe Search
  2. Type the item name (e.g., "Iron Ore")
  3. Press Enter or click Search
  4. View the crafting recipe

Auto-Click:
  1. Press F6 to toggle auto-clicking
  2. Label changes color when active (green = ON)
  3. Press F6 again to disable

Moving the Window:
  - Click and drag anywhere on the overlay to move it

TROUBLESHOOTING
---------------
Q: Windows says "Windows protected your PC"
A: Click "More info" → "Run anyway"
   (This is normal for unsigned executables)

Q: My antivirus blocks the app
A: Add an exception for RM-Insta-Depo.exe
   (This is a false positive - the app is safe)

Q: The overlay is too small/large
A: This is a DPI scaling issue - the app auto-adjusts
   If problems persist, try changing Windows display scaling

Q: Hotkeys don't work in game
A: Make sure the game window is active and in focus

Q: Recipe search shows no results
A: Check your spelling - search is case-insensitive


CONTEXT MENU (Right-Click on Overlay)
--------------------------------------
- Pause Hotkeys - Temporarily disable all hotkeys
- Resume Hotkeys - Re-enable hotkeys
- Toggle Auto Click - Turn auto-click ON/OFF
- Recipe Search - Open recipe search window
- Change Resolution - Open resolution selector
- Exit - Close the application


TIPS & TRICKS
-------------
1. Pin the overlay to a corner where it won't obstruct your game
2. Use F8 to hide the overlay when you don't need it
3. Recipe search is case-insensitive (try "iron" or "IRON")
4. You can move the overlay while it's running
5. Right-click the overlay for quick access to features
