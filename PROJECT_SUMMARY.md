## 🚀 How to Create Standalone App

### Quickest Method (2 minutes):
1. Install AutoHotkey from https://www.autohotkey.com/
2. Right-click on `RM-Insta-Depo_S6_v2.ahk`
3. Select "Compile Script"
4. Done! You have `RM-Insta-Depo_S6_v2.exe`

### Automated Method (5 minutes):
1. Install AutoHotkey
2. Double-click `compile.bat`
3. Get `RM-Insta-Depo.exe` (better name)

### Professional Installer (20 minutes):
1. Install AutoHotkey and Inno Setup
2. Run `compile.bat` to create EXE
3. Open Inno Setup Compiler
4. Load `installer_script.iss`
5. Click "Compile"
6. Get professional Windows installer!

See **DISTRIBUTION_GUIDE.md** for complete details.
