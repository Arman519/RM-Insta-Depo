EVENT FLOW & INTERACTIONS
─────────────────────────────────────────────────────────────────────────────

User Interaction                Handler Function              Action
─────────────────────────────────────────────────────────────────────────────
Press F1                    →  F1::Macro1                  Execute macro
Press F2                    →  F2::Macro2                  Execute macro
Press F3                    →  F3::Macro3                  Execute macro
Press F4                    →  OpenRecipeSearch             Show Recipe GUI
Press F5                    →  OpenResSelector              Show Resolution GUI
Press F6                    →  ToggleAutoClick              Toggle auto-click
Press F8                    →  GuiClose Event              Toggle main window

Right-click Window          →  ShowContextMenu              Display context menu
Left-click (drag title)     →  StartDrag                    Enable drag mode
Mouse Move (hover)          →  HandleMouseMove              Change button colors

Resolution Selection        →  ApplyResolution              Update coordinate set
Recipe Search               →  PerformSearch                Query recipe DB
Auto-click Toggle           →  PerformAutoClick (timer)     Execute clicks

Clock Update (every 1s)     →  UpdateClock (timer)          Display current time
Game Detection (every 1s)   →  CheckGameActive              Toggle transparency

LIMITATIONS & TECHNICAL ISSUES
─────────────────────────────────────────────────────────────────────────────

Architecture Issues:
  ├─ UI & macro logic mixed in same file
  ├─ No separation of concerns
  ├─ Hardcoded pixel coordinates for all UI elements
  ├─ Coordinate database for macros: 100+ click positions per resolution
  └─ No configuration file system

Styling Issues:
  ├─ Only 5 colors in entire application
  ├─ No visual hierarchy or depth
  ├─ Inconsistent spacing (10-30px, no guidelines)
  ├─ No differentiation between interactive & static elements
  ├─ Poor contrast in some areas
  └─ No hover/focus states for text controls

Usability Issues:
  ├─ Fixed window size (not resizable)
  ├─ Small UI feels cramped
  ├─ No tooltips explaining hotkeys
  ├─ Recipe search has no filtering/categories
  ├─ No recent items or favorites
  └─ Help documentation missing from UI

Performance Issues:
  ├─ Mouse movement detection: constant polling
  ├─ No idle optimization
  ├─ Clock updates even when window is hidden
  ├─ All timers run at fixed intervals regardless of state
  └─ No resource cleanup on exit


FRAMEWORK CAPABILITIES & LIMITATIONS
─────────────────────────────────────────────────────────────────────────────

AutoHotkey v1 Capabilities:
  ✓ Basic windows with hardcoded sizes

AutoHotkey v1 Limitations:

  ✗ No component library
  ✗ No DPI awareness
  ✗ No built-in data binding
  ✗ Limited accessibility features
